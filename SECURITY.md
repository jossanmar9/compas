# Seguretat de Compàs

Compàs gestiona dades personals i econòmiques, també de menors. Si trobes una possible vulnerabilitat, comunica-la **en privat**, encara que el programa funcione només en un ordinador.

## Comunicar una vulnerabilitat

Escriu a [compas.lliure@gmail.com](mailto:compas.lliure@gmail.com) amb l'assumpte **[Seguretat Compàs]**. Pots escriure en valencià o castellà. Este és el canal de contacte del mantenidor; no cal obrir una incidència ni una PR pública.

En el primer missatge, inclou només:

- La versió de Compàs, el sistema operatiu i, si és rellevant, el tipus d'entitat.
- L'apartat afectat, què podria fer una persona atacant i quin accés necessitaria.
- Els passos mínims per a reproduir-ho en una instal·lació de proves amb dades inventades.
- L'impacte que has observat i captures o fragments tècnics revisats, si ajuden a entendre'l.

**No envies dades reals de persones, IBAN reals, contrasenyes, codis de recuperació, bases de dades ni còpies de seguretat**, ni tan sols per correu. El correu ordinari no és un canal amb xifrat d'extrem a extrem. Si cal intercanviar material sensible, acordarem abans com fer-ho.

No publiques els detalls que permeten explotar el problema en una issue, una PR o un comentari. Evita provar-lo en instal·lacions d'altres entitats o sobre dades reals.

## Versions i seguiment

Les correccions de seguretat es preparen per a l'última versió estable publicada. No es garanteixen correccions separades per a versions antigues. Consulta les [versions publicades](https://github.com/jossanmar9/compas/releases) i indica sempre la versió en què has detectat el problema.

El mantenidor revisarà l'avís i podrà demanar aclariments o una reproducció amb dades inventades. Quan es confirme el problema, es coordinarà la correcció i la publicació dels detalls amb qui l'haja comunicat. És un projecte mantingut de manera voluntària: no hi ha un termini de resposta o de resolució garantit. El reconeixement públic de qui informe s'acordarà amb eixa persona.

Per a errors de funcionament sense impacte de seguretat, utilitza les [plantilles d'incidències](https://github.com/jossanmar9/compas/issues/new/choose). Per a consultes sobre el tractament de dades, consulta [PRIVACITAT.md](PRIVACITAT.md).

## Seguridad de Compàs

Si encuentras una posible vulnerabilidad, escribe **en privado** a [compas.lliure@gmail.com](mailto:compas.lliure@gmail.com) con el asunto **[Seguridad Compàs]**. No abras una issue, una PR ni un comentario público con los detalles que permitan explotarla.

Indica la versión, el sistema operativo, la parte afectada, el acceso que necesitaría una persona atacante, el impacto y los pasos mínimos para reproducirlo con datos inventados. No envíes datos personales, IBAN reales, contraseñas, códigos de recuperación, bases de datos ni copias, tampoco por correo. El correo ordinario no tiene cifrado de extremo a extremo; si hace falta material sensible, acordaremos antes cómo compartirlo. No pruebes el problema sobre instalaciones ajenas ni datos reales.

Las correcciones se preparan para la última versión estable; no se garantizan correcciones independientes para versiones antiguas. El mantenedor revisará el aviso y coordinará la corrección y la divulgación con quien lo comunique. El proyecto es voluntario y no garantiza plazos de respuesta o resolución. El reconocimiento público se acordará con la persona que informe. Los errores sin impacto de seguridad se notifican con las [plantillas de incidencias](https://github.com/jossanmar9/compas/issues/new/choose).
